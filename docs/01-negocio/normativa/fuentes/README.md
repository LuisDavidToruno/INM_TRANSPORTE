# Fuentes normativas primarias

Los documentos oficiales de los que salen las afirmaciones `[V]` de las fichas `NRM-xx`.

**Están versionados a propósito.** Un enlace a `tsc.gob.hn` puede caerse en tres años, y este sistema tiene que poder mostrarle a un auditor **contra qué norma exacta** calculó algo en 2026. La premisa rectora del proyecto es que todo registro puede ser requerido por el Tribunal Superior de Cuentas; la norma que lo respalda no puede depender de que un sitio siga en pie.
